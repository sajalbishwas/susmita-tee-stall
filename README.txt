সুস্মিতা টি-স্টল — লোগোসহ Android PWA ডেমো

এই ZIP-এ অ্যাপের লোগোটি অ্যাপ আইকন (192px/512px) এবং অ্যাপের উপরের অংশে যুক্ত করা হয়েছে।

Android-এ ইনস্টল করার নিয়ম:
1) ZIP ফাইলটি extract করুন।
2) ভেতরের সব ফাইল ও icons ফোল্ডার একসাথে HTTPS ওয়েব হোস্টিংয়ে প্রকাশ করতে হবে।
3) Android ফোনে Chrome দিয়ে প্রকাশিত ওয়েব ঠিকানা খুলুন।
4) Chrome-এর ⋮ মেনু > Install app (বা Add to Home screen) চাপুন।
5) ইনস্টল হলে ফোনের অ্যাপ তালিকায় “সুস্মিতা টি-স্টল” আইকন দেখা যাবে।

শুধু ZIP ডাউনলোড বা index.html খোলার মাধ্যমে সরাসরি APK ইনস্টল হবে না। এটি APK নয়; HTTPS-এ হোস্ট করার পর PWA হিসেবে ইনস্টল হবে।

ডেমোর ফিচার: নগদ/বাকি বিক্রি, কাস্টমার কোড-নাম-ছবি-মোবাইল, কাস্টমার খাতা ও টাকা জমা, কেনাকাটার হিসাব, সময়-তারিখ, CSV ও JSON backup। স্টক গণনা নেই।

গুরুত্বপূর্ণ: ডেটা এই ডিভাইসের ব্রাউজারে থাকে। Firebase/Gmail cloud backup, বহু ফোনে sync, নিরাপদ owner/employee login, Recycle Bin, cloud recovery এবং native APK এখনো যুক্ত হয়নি। বাস্তব দোকানে ব্যবহারের আগে এগুলো তৈরি ও পরীক্ষা করতে হবে।
